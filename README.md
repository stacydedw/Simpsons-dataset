# Анализ и классификация датсета Simpsons

Набор данных содержит информацию о персонажах из мультсериала "Симпсоны". Датсет включает различные характеристики персонажей и целевую переменную, определяющую выживание или другой бинарный исход.

Датсет содержит информацию о различных аспектах персонажей, включая демографические данные, социальные связи и другие характеристики. Один из видов персонажей отличается от двух других, два других выглядят линейно пропорционально друг другу.

- **EDA**: сводная статистика, проверка пропусков, анализ распределений признаков
- **Предобработка**: обработка пропущенных значений (заполнение средним/модой), кодирование категориальных переменных, создание новых признаков (возрастные группы: Age_20_35, Age_35_50, Age_50_80), удаление нерелевантных признаков (PassengerId, Ticket, Name)
- **Визуализация**: гистограммы распределения признаков, круговые диаграммы распределения целевой переменной
- **Корреляционный анализ**: анализ взаимосвязей между признаками
- **Классификация**: Random Forest Classifier (accuracy, precision, recall, F1-score, confusion matrix, classification report)

- **Язык**: Python 3.14.2
- **Среда**: Jupyter Notebook
