# Анализ и классификация датсета Simpsons

Датасет The Simpsons Characters Dataset содержит кадры из мультсериала «Симпсоны» с разметкой по персонажам. Всего в разметке присутствует несоответствие с реальным числом персонажей во вселенной (43), а сами классы распределены неравномерно — некоторых героев в кадрах в разы больше, чем других, что делает задачу интересной с точки зрения работы с несбалансированными данными и компьютерным зрением.

Задача — научиться по изображению определять, какой из 18 наиболее часто встречающихся персонажей на нём изображён, используя перенос обучения на предобученной сверточной сети. Библиотеки: TensorFlow, Keras, pandas, scikit-learn, matplotlib, seaborn

- **EDA**: анализ количества изображений по классам, выявление дисбаланса классов, визуализация распределения (barh-график)
- **Предобработка**: разбиение на train/val/test (70/15/15) со стратификацией по классам, раскладка файлов по папкам под соответствующие выборки
- **Аугментация данных**: повороты, сдвиги по ширине/высоте, отражение по горизонтали, масштабирование, изменение яркости — для борьбы с переобучением и дисбалансом классов
- **Модель**: transfer learning на предобученной ResNet50 (веса ImageNet, без верхних слоёв) с добавленными GlobalAveragePooling2D, Dense и Dropout слоями
- **Обучение**: EarlyStopping (мониторинг val_accuracy) и ReduceLROnPlateau (мониторинг val_loss) для стабилизации и предотвращения переобучения
- **Оценка качества**: confusion matrix по 18 классам, анализ графиков accuracy/loss на train и validation

- **Язык**: Python
 **Среда**: Jupyter Notebook
